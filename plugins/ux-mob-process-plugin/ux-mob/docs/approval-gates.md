# Approval Gates

The AI is strictly instructed to never run away and do the whole project at once. It works phase by phase. 

At the end of every phase, the AI will stop and ask you:

**Phase review required.**
1. Approve and continue
2. Revise this phase
3. Add missing information
4. Pause the process

To move forward, you must explicitly say "Approve and continue" or "Approved". If you don't like the result, tell the AI what to fix!

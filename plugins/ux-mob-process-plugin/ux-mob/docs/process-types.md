# Process Types

## Greenfield
Use this process when you are building a product from scratch with no existing codebase, users, or legacy systems to worry about.

## Brownfield
Use this process when working on a product that already exists. 

Because AI agents can easily hallucinate when they don't know the full context of an existing product, **AI Readiness** must be achieved first. Once ready, you can run:
- **Add New Feature:** Designing something completely new that fits into the existing ecosystem.
- **Complete Revamp:** Overhauling an entire section or the whole app.
- **Improve Existing Feature:** Making targeted optimizations to a specific workflow or screen.
